# 生活科技探險隊

使用 Phaser 3 製作的國小生活科技闖關遊戲。共有五個主題關卡，每關兩題，共十題；完成第五關第二題後進入結算畫面。角色走近答案即可蒐集。答對加 10 分、答錯扣 5 分，總分超過 40 分即可獲得榮譽勳章。

## 開始遊玩

在此資料夾執行：

```sh
python3 -m http.server 8000
```

接著用瀏覽器開啟 `http://localhost:8000`。遊戲透過 cdnjs 載入 Phaser 3.90.0，因此第一次開啟時需要網路連線。

## 操作

- 使用方向鍵或 WASD 移動角色；手機／平板可使用畫面下方的方向鈕。
- 走近答案卡片就會自動蒐集，並顯示答題結果和生活科技小知識。
